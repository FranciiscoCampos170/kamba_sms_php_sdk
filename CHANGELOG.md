# Changelog

## 2.0.0

- Atualiza a URL padrão para `https://api.kambasms.ao`.
- Adiciona Verify, Lookup, Notify, Email e Transactions.
- Adiciona estatísticas, consumo, bulk e agendamentos.
- Adiciona idempotência, request ID, timeout e erros de transporte com estado `0`.
- Corrige a compatibilidade real com PHP 8.0 removendo propriedades `readonly`.
- Adiciona testes de contratos HTTP e documentação dos produtos.
